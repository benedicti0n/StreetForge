# StreetForge

> Draw your getaway. Forge it into a world. Escape the pursuit.

StreetForge is an original, GTA VI-inspired browser experience: you sketch a
top-down driving map with a full image editor, an AI world model forges it into
a drivable 3D environment, and you race through your own creation while the
police close in.

## Experience

```text
Draw
→ Generate
→ Drive
→ Escape
```

1. **Sketch a world** — roads, vegetation, ramps and open space on a blank map.
2. **Forge it into 3D** — the sketch is sent to World Labs Marble and becomes a
   real gaussian-splat environment with physics collision.
3. **Outrun the police** — 3-2-1-GO, drive your getaway, stay ahead of the
   pursuit, and win the escape or get busted.

## Environment

Create a `.env.local` (or `.env`) with the World Labs API key and model
preferences:

```text
WLT_API_KEY=
WORLDLABS_API_BASE_URL=
WORLDLABS_DRAFT_MODEL=
WORLDLABS_FINAL_MODEL=
WORLDLABS_MOCK_MODE=
```

Only variables your deployment actually uses are required; `WLT_API_KEY` is the
one that matters. `WORLDLABS_MOCK_MODE=true` switches the API to a local mock
for offline development. The API key never leaves the server and never enters
client bundles.

## Local setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`. For a production build:

```bash
npm run build
npm run start
```

## Architecture

- `components/workspace/` — top-level split layout (3D viewport + editor) and
  the experience state provider boundary.
- `components/world/` — the 3D world: experience state machine, viewport,
  generated-world loading (splat + collider), vehicle physics, police chase,
  procedural audio, game HUD/countdown/results.
- `components/map-editor/` — the Unlayer-based sketch editor and the
  generation header/progress UI.
- `app/api/world/` — server-only Marble proxy routes (generate, poll, refetch
  by world id). The API key is read only here, on the server.
- `lib/worldlabs/` — Marble client, types, and shared configuration.

The game lifecycle is a single state machine: `editing → generating →
world-ready → countdown → playing → escaped/busted`, with `run it back`
reusing the same generated world (zero new generations).

## AI-generated environment disclosure

Worlds are generated by World Labs Marble from the user's sketch. Generated
worlds are AI-produced environments; layout fidelity follows the sketch but is
not guaranteed to be pixel-perfect.

## Live integration notes

Verified against real Marble Draft generations:

- **Draft may omit semantic scale metadata** (`metric_scale_factor` /
  `ground_plane_offset` can be absent). StreetForge falls back to measuring
  the collider footprint to derive a playable scale.
- **Safe spawn prefers base terrain**: spawn rays cast to the deepest surface
  and stay near the low percentile of terrain height, avoiding elevated
  highway and ramp rooftops.
- **Signed assets may expire**: if a world's asset URLs stop loading, the app
  refetches the world metadata once (same world id, no new generation) and
  retries before surfacing an error.
- **500k splat tier is the gameplay default** (100k is available as a low
  quality setting for weaker GPUs).
